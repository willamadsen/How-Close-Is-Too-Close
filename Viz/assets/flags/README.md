# Flags

Country flags shown next to satellite names on the compare page.

- All flags except `su.svg`: [flag-icons](https://github.com/lipis/flag-icons) 7.2.3 (MIT License, see `LICENSE-flag-icons.txt`). A `width="640" height="480"` was added to each file so browsers can draw it onto a canvas.
- `su.svg` (Soviet Union): [Wikimedia Commons, Flag_of_the_Soviet_Union.svg](https://commons.wikimedia.org/wiki/File:Flag_of_the_Soviet_Union.svg), public domain.

Which flag goes with which owner code is in `../../data/owners.json`.
